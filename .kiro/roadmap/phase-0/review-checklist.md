# Phase 0 Review Checklist

Use named reviewers and dates. A checked box records approval evidence; it does not replace review notes.

## Product review

Reviewer:  
Date:

- [ ] Course-agnostic product boundary is approved.
- [ ] AIP-C01 is approved as the first course.
- [ ] Target learner, prerequisites, and intended outcome are approved.
- [ ] Consumer, team, or staged commercial direction is recorded.
- [ ] Readiness language avoids promising exam success.

Decision: approve / revise  
Notes:

## Subject-matter review

Reviewer:  
Qualification:  
Date:  
Official guide version or retrieval date:

- [ ] Skills are measurable at the intended professional level.
- [ ] Evidence requirements are appropriate.
- [ ] Prototype material is technically accurate.
- [ ] No copied or dump-derived questions are present.
- [ ] Missing scope and unresolved curriculum risks are recorded.

## Instructional review

Reviewer:  
Date:

- [ ] Prototype can run in 25 to 35 minutes.
- [ ] Baseline and final prompts measure comparable capability.
- [ ] Hints are progressive and do not disclose the solution.
- [ ] Facilitator script limits inconsistent teaching.
- [ ] Rubric levels are distinguishable from observable evidence.
- [ ] Participant burden and accessibility risks are acceptable.

Decision: approve / revise  
Notes:

## Engineering review

Reviewer:  
Date:

- [ ] Course-specific behavior remains outside the shared core.
- [ ] State machine boundaries and durable state are explicit.
- [ ] Platform interfaces preserve desktop, web, and mobile portability.
- [ ] Event-based progress and conflict behavior are acceptable.
- [ ] Lab lifecycle remains provider-neutral.
- [ ] Deferred provider decisions have clear decision points.

Reviewer:  
Date:
